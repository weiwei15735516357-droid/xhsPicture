# 阶段三：素材池与成品导出功能文档

## 目标

阶段三要把当前已经生成或导入的图片集中管理起来：图片不只是显示路径，而是进入一个可用的素材池，用户可以查看、筛选、预览、删除、打开所在文件夹，并给后续透视合成复用。

文档转图和叠图排版已经在前面实现，本阶段不重复开发。拼图模块也不进入本阶段。后续透视合成、飞书上传会复用这一套素材池能力。

## 使用场景

1. 用户把 PPT/Word/PDF 转成多张小红书图片。
2. 用户在素材池里快速查看生成结果。
3. 用户删除不满意的图片，保留可用图片。
4. 用户可以打开素材所在文件夹，方便直接检查或上传。
5. 用户可以删除素材记录，必要时同时删除本地文件。

## 功能范围

### 素材池

素材池展示当前项目下所有已登记图片，包括：

1. 文档页图片。
2. 叠图汇总图片。
3. 手动导入图片。
4. 后续阶段生成的透视合成图、拼图成品图。

素材列表展示字段：

1. 缩略图。
2. 文件名。
3. 来源类型。
4. 图片尺寸。
5. 文件大小。
6. 创建时间。
7. 所在路径。

素材池操作：

1. 单选图片。
2. 多选图片。
3. 全选/取消全选。
4. 预览大图。
5. 打开所在文件夹。
6. 从素材池删除记录。
7. 可选：同时删除本地文件。

### 筛选与排序

第一版做轻量筛选：

1. 按来源类型筛选：全部、文档页、汇总图、导入图片、成品图。
2. 按文件名搜索。
3. 按创建时间排序。
4. 按文件名排序。

## 暂不包含

1. 不做图片编辑。
2. 不做文字叠加。
3. 不做拼图模板。
4. 不做透视合成。
5. 不做飞书上传。
6. 不做文档转图重复开发。
7. 不做成品批量导出。
8. 不做复杂标签系统。

这些功能放到后续阶段。

## 界面规划

### 工作台主区域

当前工作台保留“PPT/Word/PDF 转 PNG”和“任务状态”。

素材池区域升级为真正可操作列表：

1. 顶部工具栏：
   - 搜索框。
   - 来源筛选。
   - 排序选择。
   - 全选按钮。
   - 刷新按钮。
2. 图片网格：
   - 每张图片一个卡片。
   - 显示缩略图、文件名、来源、尺寸。
   - 支持点击选中。
3. 右侧或弹窗预览：
   - 显示大图。
   - 显示路径、尺寸、文件大小。
   - 操作按钮：打开文件夹、删除、导出选中。

## 后端接口

### 素材列表

```text
GET /api/assets
```

新增查询参数：

```text
project_dir
source_type
q
sort
```

### 素材删除

```text
DELETE /api/assets/{asset_id}
```

请求参数：

```json
{
  "project_dir": "...",
  "delete_file": false
}
```

## 数据结构调整

素材记录继续保存在项目 `project.json` 里。

建议补充字段：

```json
{
  "id": "...",
  "path": "...",
  "filename": "...",
  "source_type": "汇总图",
  "width": 1080,
  "height": 1440,
  "file_size": 1234567,
  "created_at": "2026-05-24T10:00:00"
}
```

已有素材如果缺少宽高和大小，刷新素材池时可以补齐。

## 验收标准

1. 能看到当前项目全部素材图片。
2. 图片卡片能显示缩略图、文件名、来源类型、尺寸。
3. 能按来源类型筛选。
4. 能按文件名搜索。
5. 能多选素材。
6. 能预览大图。
7. 能打开图片所在文件夹。
8. 能从素材池删除素材记录。
9. 勾选“同时删除文件”时，本地图片也被删除。
10. 文档转图生成的新图片会自动进入素材池。
11. 素材池后续可以作为透视合成的选图入口。

## 推荐开发顺序

1. 后端补齐素材元数据：宽高、大小、创建时间。
2. 后端实现素材筛选、删除接口。
3. 前端把素材池从文本列表升级为图片网格。
4. 前端增加预览、删除、打开文件夹。
5. 全量测试和桌面程序重启验证。
