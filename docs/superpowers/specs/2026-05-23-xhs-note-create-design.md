# 小红书图片笔记闭环工具设计

## 背景

本项目是一个 Windows 单机桌面工具，用于制作小红书图片笔记、小红书商品主图和详情图。工具采用 Python + Electron 开发，Electron 使用本机路径 `D:\WindowsUtils\Electron\electron-v30.5.1-win32-x64`。

用户主要自己单机使用，不需要账号体系、团队协作、云同步、自动更新、AI 生成模型或图标生成能力。第一版目标是跑通从素材导入、文档转图、场景合成、拼图排版、成品导出到飞书随机上传的本地闭环。

## 产品目标

第一版做成“闭环工作台”，默认流程为：

```text
导入文档/图片 -> 转 PNG/入素材池 -> 透视合成或拼图 -> 导出成品图 -> 可选随机上传飞书
```

工具需要同时支持文档素材和现成图片素材。文档来源包括 Word、PPT、PDF；图片来源包括单张图片和图片文件夹。所有素材最终进入统一图片素材池，后续合成、拼图、导出和飞书上传都从素材池或成品目录取图。

## 第一版范围

### 包含

1. 导入 Word、PPT、PDF、图片文件和图片文件夹。
2. Word/PPT 使用本机 Microsoft Office 转换。
3. PDF 使用本地渲染库按倍率输出 PNG。
4. 支持文档转换清晰度倍率、页数限制和按源文件创建子文件夹输出。
5. 建立统一图片素材池，支持预览、删除和打开所在文件夹。
6. 场景透视合成支持上传场景图和叠图，并通过四角拖拽做透视变换。
7. 拼图排版支持小红书常用比例、图片坑位、文字元素和叠加图片元素。
8. 支持保存拼图模板，并批量填充图片生成成品图。
9. 成品图支持 PNG/JPG 导出、清晰度选择、命名规则和子文件夹输出。
10. 飞书模块支持配置 App ID、App Secret、多维表格链接、表 ID、附件字段名和行范围。
11. 飞书模块支持测试连接、随机抽图上传到指定行附件字段和任务日志。

### 暂不包含

1. 不做 AI 生成图、模型处理或图标生成。
2. 不做小红书平台自动发布。
3. 不做多人账号、云同步或自动更新。
4. 不做复杂素材资产管理。
5. 不做自动识别场景透视区域。
6. 不做复杂飞书筛选规则和商品名自动匹配。

## 技术架构

### 总体结构

Electron 负责桌面壳和 GUI，Python 负责本地服务与重任务处理。启动时 Electron 拉起 Python 后端，前后端通过 `127.0.0.1` 本地 HTTP 通信。

建议后端端口默认为 `8787`，如端口被占用则自动寻找可用端口，并把端口写入启动状态。

### Electron 职责

1. 启动和关闭 Python 后端。
2. 提供文件选择、目录选择、页面导航和参数表单。
3. 显示素材池、任务进度、图片预览和日志。
4. 提供透视合成四角拖拽交互。
5. 提供拼图模板编辑画布。
6. 调用 Python 本地 API，不直接执行重图像任务。

### Python 职责

1. 提供本地 API 服务。
2. 调用 Microsoft Office 完成 Word/PPT 转换。
3. 使用 PDF 渲染库完成 PDF 转 PNG。
4. 使用图像处理库完成透视合成、拼图渲染、文字绘制和导出。
5. 管理项目目录、素材索引、模板文件、配置文件和日志。
6. 调用飞书接口完成鉴权、附件上传和字段写入。
7. 管理耗时任务进度和错误状态。

### 主要依赖

1. 本地 API：FastAPI。
2. Word/PPT 转换：pywin32 调用 Microsoft Office COM。
3. PDF 渲染：PyMuPDF。
4. 图片处理：Pillow 和 OpenCV。
5. 飞书接口：requests。
6. 配置保存：JSON 文件。
7. 任务日志：本地日志文件和 GUI 任务记录。

## 主要模块

### 工作台

工作台展示当前项目、最近任务、素材数量、成品数量和快捷入口。推荐入口包括导入素材、文档转图、透视合成、拼图排版、导出成品和飞书上传。

### 文档转图

支持 Word、PPT 和 PDF 批量转 PNG。Word/PPT 依赖本机 Microsoft Office；PDF 使用 PyMuPDF 渲染。参数包括倍率、页数范围、输出格式和是否按源文件名创建子文件夹。

失败文件不能中断整个批处理，需要记录失败文件、页码和错误原因。

### 素材池

素材池展示所有导入和生成的图片。素材需要记录 ID、文件路径、来源类型、宽高、创建时间和关联任务。来源类型包括文档页、普通图片、透视合成图、拼图成品和导出图。

### 透视合成

用户选择场景底图和叠图，在场景图上拖动四个角控制点。Python 使用 OpenCV 做透视变换，再与底图合成。第一版支持单张合成，参数包括导出尺寸、透明度、边缘羽化和阴影。

如果四角交叉、区域太小或点位非法，需要阻止导出并提示。

### 拼图排版

拼图模板支持 `3:4`、`4:5`、`1:1`、`9:16` 画布比例，长边支持 `1080`、`1440`、`2160`。模板元素包括图片坑位、文字元素和叠加图片元素。

模板保存为 JSON 文件。批量生成时，用户选择素材图片，系统按模板坑位顺序填充并导出成品图。

### 导出

导出模块支持选择素材池图片、透视合成图或拼图成品图。参数包括输出目录、格式、JPG 质量、命名规则和子文件夹策略。

命名规则第一版支持源文件名、序号和时间戳组合。

### 飞书随机上传

飞书模块第一版先做配置、测试连接、随机抽图上传和日志。用户之后建表后，填写 App ID、App Secret、多维表格链接、表 ID、附件字段名、行范围和图片目录。

上传流程为：读取图片目录 -> 按行范围获取目标行 -> 随机抽取图片 -> 上传附件 -> 写入附件字段 -> 记录行号、图片名、成功或失败原因。

## 本地配置

全局配置保存到：

```text
data/config.json
```

内容包括最近项目目录、Office 检测结果、默认导出倍率、默认画布比例、默认导出格式、飞书配置和后端端口。

项目配置保存到：

```text
项目目录/project.json
```

内容包括素材列表、文件来源、转换记录、合成图记录、拼图模板引用、导出记录和最近一次任务状态。

拼图模板保存到：

```text
项目目录/templates/*.json
```

## 异常处理

1. 没安装 Office 时，Word/PPT 转图按钮提示不可用，PDF 和图片流程仍可用。
2. Word/PPT 转换失败时，记录文件名和错误原因，不中断其他文件。
3. PDF 页码超范围时，跳过无效页并提示。
4. 图片过大时，后台执行任务，前端显示进度，界面不冻结。
5. 透视合成四角非法时，阻止导出。
6. 字体缺失时，回退到系统默认字体。
7. 飞书未配置时，上传按钮禁用，但允许保存配置。
8. 飞书鉴权失败、字段不存在或附件上传失败时，显示明确错误并写日志。
9. 中途关闭软件时，不恢复未完成任务，但已生成文件保留。

## 实现里程碑

### 阶段一：项目骨架和本地服务

1. Electron 启动 Python 后端。
2. 健康检查。
3. 设置页。
4. 项目目录创建。
5. 日志系统。

### 阶段二：素材导入与文档转 PNG

1. 图片和文件夹导入。
2. PDF 转 PNG。
3. Word/PPT 通过 Office 转换。
4. 任务进度。

### 阶段三：素材池与导出

1. 图片列表。
2. 预览和删除。
3. PNG/JPG 导出。
4. 命名规则和子文件夹输出。

### 阶段四：透视合成

1. 场景图和叠图选择。
2. 四角拖拽。
3. OpenCV 透视变换。
4. 高清导出。

### 阶段五：拼图模板

1. 画布比例。
2. 图片坑位。
3. 文字元素。
4. 模板保存。
5. 批量生成。

### 阶段六：飞书上传

1. 飞书配置保存。
2. 测试连接。
3. 随机抽图。
4. 上传附件字段。
5. 任务日志。

## 验收标准

1. 能创建本地项目目录，并生成约定目录结构。
2. 能导入图片文件夹，并在素材池看到图片。
3. 能把 PDF 转成 PNG，并支持倍率和页数范围。
4. 在安装 Office 的环境下，能把 Word/PPT 转成图片。
5. 能用四角拖拽完成一张真实透视合成图并导出。
6. 能创建一个小红书比例拼图模板，并批量生成成品图。
7. 能按指定格式导出 PNG/JPG 到指定目录。
8. 在飞书配置完整时，能测试连接并上传随机图片到指定附件字段。
9. 所有失败任务都有可读错误信息和日志记录。
